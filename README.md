## Simple Interest Calculator

A calculator that calculates simple interest given the principal, annual rate of interest (as a percentage), and time period in years.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest (percentage)
Output:
   simple interest = p * t * r / 100
```
